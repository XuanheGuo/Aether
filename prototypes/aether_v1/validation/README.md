# Vehicle-V1 第二轮验证报告

Vehicle-V1 通过了 CAD 到 MJCF 的再生成回归和五组自由刚体数值实验。试验基于第一轮冻结的概念模型，用于核对结构、装配运动和 MuJoCo 的数值响应。

## 复现

在 macOS Apple Silicon 上使用 FreeCAD 1.1.4 的内置 Python，以及独立的 Python 3.14 科学计算环境。测试版本见 [requirements.txt](requirements.txt)。进入 `prototypes/aether_v1/`，用 MuJoCo 环境里的 Python 运行以下命令。

```sh
python validation/model_regression.py --output runs/cad-regression.json
python validation/flight.py --case all --output runs/flight
```

独立交付包从 `Aether-V1-Round2/` 运行相同命令。FreeCAD 安装在其他位置时，用 `--freecad-python` 指定应用包的 `Contents/Resources/bin/python`。新 Python 环境可通过 `python -m pip install -r validation/requirements.txt` 安装依赖。

用 `--case fall|inertial|tumble|load|convergence` 选择单一工况。用 `--dt 0.005` 调整单一工况的步长，用 `--no-plots` 仅输出数值。自动校验未通过时，命令以非零状态退出。两条命令使用新输出路径，便于保留历史结果。

## CAD 与地面回归

- 在临时副本把活动面展长 `FinSpan` 从 132 mm 改为 136 mm。FreeCAD 重算并保存副本，重新打开后再导出 MJCF。只有四片活动面的实体体积和对应网格随尺寸变化。冻结模型包的 46 个文件在测试前后逐个通过 SHA-256 校验，正式样机仍为 132 mm。
- 对原版和再生成版分别核对 41 个有效实体及其可视化网格、零件所属刚体、六个铰链的父子关系、转轴和限位。网格与 CAD 实体的世界坐标包围盒最大相差 **0.120 mm**。三组采样姿态的关节位置和姿态误差分别小于 **10⁻⁹ m** 和 **10⁻⁹ rad**。
- 每版逐一测试六个关节。每个关节先接受正向 70% 行程，再接受反向 70% 行程，每个目标保持 3 秒。两版 24 次响应均达到目标方向和末态判据。原版和再生成版的最大末态误差均为 **2.77°**，合格阈值为 6°。
- 两版均通过 5 秒地面稳定性测试。在最后 1 秒，四脚均在全部采样步与地面接触。机体沉降约 **0.028 mm**。

## 自由刚体实验

每次从现有 MJCF 派生内存场景，保留 41 个 CAD 网格、各刚体显式质量与惯量，把六个铰链刚性固定在 CAD 中位。场景移除地面、接触代理和关节执行器，保留六自由度浮动基座。除自由落体外，重力设为零。各次运行检验约束数量、接触数量、求解器警告和状态有限性。

位置和线速度以整机质心为基准，姿态为机体坐标到世界坐标的单位四元数，角速度与载荷均用世界坐标。标准测试力通过 MuJoCo 的 `mj_applyFT` 作用于整机质心，力矩沿初始最大主惯量轴。质心平移用常加速度公式核对，沿主轴旋转用常角加速度公式核对。任意轴翻滚用世界系角动量和动能守恒核对。 [MuJoCo 函数参考](https://mujoco.readthedocs.io/en/latest/APIreference/APIfunctions.html)

| 工况 | 2 秒试验结果 |
| --- | --- |
| 自由落体 | 重力为 −9.81 m/s²，速度最大误差 1.85 × 10⁻¹³ m/s，位置误差 19.62 mm，符合 2 ms 步长的半隐式位置积分误差 |
| 无外力惯性运动 | 初速度 (1.3, −0.7, 0.25) m/s，质心位置最大误差 6.14 × 10⁻¹³ m |
| 无力矩翻滚 | 质心初速度为零，角速度有三个主轴分量。以 2 ms 的 MuJoCo RK4 积分，角动量向量与动能的最大相对漂移分别为 7.56 × 10⁻¹³ 和 1.12 × 10⁻¹⁴ |
| 标准外载响应 | 质心恒力 (2, −1, 0.75) N，主轴恒力矩 0.60 N·m。以 2 ms 的 implicitfast 积分，位置与姿态最大误差分别为 0.464 mm 和 0.449 mrad |
| 步长收敛 | 标准载荷工况在 20、10、5、2.5 ms 下复跑。位置误差从 4.64 降至 0.581 mm，姿态误差从 4.49 降至 0.561 mrad，拟合阶数分别约为 0.999 和 1.000 |

初始姿态为 CAD 中位。惯性运动和标准载荷实验从零角速度开始。自由落体、惯性运动、标准外载与收敛使用 `implicitfast`。CSV 包含时间、质心状态、机体姿态、角速度、测试载荷、重力和适用的逐样本误差。无解析姿态参考的翻滚工况使用守恒量误差，CSV 对不适用列留空。每次运行生成 `summary.json` 和各工况的 CSV，默认同时绘制 PNG。

## 验证边界与下一阶段

已验证的是冻结几何在已定义试验中的数值一致性、理想自由刚体响应和地面机械回归。**11.409 kg** 及主惯量来自 CAD 与概念密度假设。真实飞行性能、内部接触、关节柔性和实际执行器性能仍需实测建模。

1. 实测总质量、各组件质量、三轴质心与惯量张量，建立测量误差和装配配置记录。
2. 台架辨识关节摩擦、回差、刚度、力矩和速率，并建立外载下的机械间隙与接触验证。
3. 通过独立实验建立适用于项目工况的推进载荷与气动载荷模型，记录有效范围和不确定性。
4. 建立传感器标定、时间同步和独立测试数据集，分别验证数值积分、外载模型与整机响应。
