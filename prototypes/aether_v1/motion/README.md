# Aether Vehicle-V1 · 首次离地与姿态实验

概念质量为 **11.4091 kg** 的 Vehicle-V1 在 MuJoCo 4.0.1 中承受沿世界 +Z 的理想测试力。力施加于整机瞬时质心，模拟器计算接触、离地、断载后的弹道段和回落。另在独立的无接触场景中观察无外力矩的姿态运动。

## 一条命令运行

在仓库或交付包根目录，使用 Python 3.12 安装现有验证环境。macOS 的原生被动 Viewer 由 MuJoCo 自带的 mjpython 启动。 [MuJoCo 原生 Viewer](https://mujoco.readthedocs.io/en/stable/python.html#passive-viewer)

```sh
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r prototypes/aether_v1/validation/requirements.txt
.venv/bin/mjpython -m prototypes.aether_v1.motion.experiment --output runs/first-motion --view vertical
```

将 `--view vertical` 换成 `--view tumble` 可观察自由转动。也可选择 `axis` 或 `inertia_variant`。每次使用新的输出目录。窗口以约半速显示实时积分，支持原生鼠标视角操作。关闭窗口后命令继续写完所有用例的 CSV、JSON 与图表。无界面执行可将 mjpython 换成 python 并省略 `--view`，任何一项验收失败时返回非零退出码。由原始 CSV 重画图表的命令如下。

```sh
.venv/bin/python -m prototypes.aether_v1.motion.plots runs/first-motion
```

## 模型与实验参数

复用冻结 MJCF 的网格、装配、质量和惯量，FreeCAD 和原始 MJCF 文件保持原样。实验场景在内存中派生，沿用已有验证工具，将六个关节固定在 CAD 中性位置并移除驱动，只保留整机自由关节。离地场景保留冻结模型的地面与接触代理。姿态场景移除接触并将重力设为零。两者均关闭风、流体和被动阻尼。Viewer 持有独立的显示模型，复制实际积分的状态，每 20 ms 仿真时间最多同步一帧。

- **离地。** 世界重力为 −9.81 m/s²。0–0.4 s 无测试载荷，0.4–1.0 s 为重量的 75%（83.943 N），1.0–2.0 s 为 125%（139.904 N），2.0 s 起断载。主步长 2 ms，另跑 1 ms。积分器为 MuJoCo implicitfast。
- **姿态。** 初始绕模型 X 轴倾斜 8°，初始质心速度为零。最小主轴用例的初始角速度为 0.55 rad/s。另两组均采用体轴角速度 (0.28, 0.18, 0.48) rad/s。惯量对照仅在实验模型中将主机身的 Izz 增加 0.08 kg·m²，整机最小主惯量从 0.15442 变为 0.23442 kg·m²，质量和质心保持一致。两组的初始角动量和动能随惯量而变。时长 4 s，步长 2 ms，积分器为 MuJoCo RK4。

## 实测与误差

| 离地指标 | 实测结果 |
| --- | ---: |
| 75% 载荷阶段平均法向支持力 | 27.981 N |
| 首次脱离 / 首次重新接触 | 1.002 / 2.810 s |
| 峰值质心升高 | 1.533 m |
| 离地载荷期平均竖直加速度 | +2.4525 m/s² |
| 断载自由段平均竖直加速度 | −9.810 m/s² |
| 接触外最大位置误差，2 ms / 1 ms | 5.479 / 2.739 mm |
| 接触外最大速度误差，2 ms | 3.51 × 10⁻¹⁴ m/s |

解析轨迹从首次无接触的原生样本取初值，再用两个常加速度段计算。误差统计覆盖脱离到重新接触前，差分加速度校验另外避开切换点。总外力包含测试力、重力和接触力。CSV 同时记录合力除以质量得到的加速度与质心速度的中心差分。冲击峰保留在 CSV，图中限制纵轴以便看清接触外区间。步长减半的位置误差比约 **2.00**，与该常加速离散更新的一阶位置误差相符。

最小主轴姿态解析误差为 **2.27 × 10⁻¹⁵ rad**。多轴转动两组在 4 s 的姿态相差 **2.085°**。所有姿态用例的世界角动量最大相对漂移低于 **2.5 × 10⁻¹⁴**，动能最大相对漂移低于 **1.2 × 10⁻¹⁴**。这些数字衡量指定初始条件下的数学一致性。接触参数及惯量仍为概念估计，测试力只用于验证基本动力学。实物 EDF 性能、气动、主动控制和真实离地性能需要单独测量和验证。

数据包含所有用例及半步长的原始 CSV、摘要、图表和原生 Viewer 截图。四元数顺序为 wxyz。位置、线速度、力及角动量在世界系中，角速度分别记录世界系和体轴系。 [已有自由刚体验证工具](../validation/README.md)

M1 MacBook Pro 8 GB 上实际打开离地和多轴转动窗口，分别同步 176 和 201 帧。两次 Viewer 运行与无界面运行的五份状态 CSV 逐字节一致。macOS 采样的两个 Viewer 运行最大常驻内存约为 594 MiB 和 538 MiB。仓库 CI 从源重新运行解析检查和图表生成。
